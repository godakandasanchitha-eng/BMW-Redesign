<h1>BMW.LK Redesign</h1>

<p>
A cinematic redesign concept for the official BMW Sri Lanka website, built using 
HTML, CSS, and JavaScript.
</p>

<hr>

<h2>Project Overview</h2>

<p>
This project is a modern front-end redesign proposal for 
<a href="https://www.bmw.lk" target="_blank">BMW.lk</a>.
The goal is to create a premium digital experience inspired by modern luxury automotive websites while maintaining BMW’s brand identity.
</p>

<p>
The redesign focuses on:
</p>

<ul>
  <li>Luxury visual storytelling</li>
  <li>Cinematic hero sections</li>
  <li>Minimal editorial UI</li>
  <li>Smooth animations and transitions</li>
  <li>Responsive layouts</li>
  <li>Modern UX patterns</li>
</ul>

<hr>

<h2>Design Direction</h2>

<p><strong>Theme:</strong> Obsidian Precision</p>

<ul>
  <li>Deep black luxury aesthetic</li>
  <li>BMW blue accent system</li>
  <li>Massive cinematic typography</li>
  <li>Minimal layouts with generous whitespace</li>
  <li>Subtle grain overlays and motion effects</li>
</ul>
