# BMW Redesign

Premium automotive website redesign built with React, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Setup

1. `npm install`
2. `npm run dev`

## Project structure

- `src/` — application source files
- `src/components/` — reusable UI components and layout
- `src/pages/` — page-level views
- `src/sections/` — editorial sections and page blocks
- `src/styles/` — global styling, tokens, and utilities
- `src/data/` — mock data for vehicles and galleries
- `src/animations/` — motion presets and interactions
- `src/hooks/` — reusable React hooks
- `src/utils/` — utility helpers
